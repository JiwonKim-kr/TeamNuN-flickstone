# source-command-art-lock

사람이 선택한 컨셉을 바탕으로 화풍을 잠글 때 사용한다. 전투 감각이 승인되기 전에는 실행하지 않는다.

## 승인 전 준비

1. `AGENTS.md`, `pipeline/commands/art.md`, `docs/command-catalog.md`를 읽고 현재 단계 제한을 확인한다.
2. 사람이 선택한 5~15장의 컨셉과 권리·출처를 확인한다. 선택이 없으면 진행하지 않는다.
3. 스타일 잠금에 맞는 커스텀 모델 학습 작업을 준비하고 실행한다. API 키나 비밀값은 출력하지 않는다.
4. 고정 프롬프트로 테스트 샘플을 생성해 원본 컨셉과 비교한다.
5. 색, 형태, 선, 재질, 금지 요소, 프롬프트 규칙을 포함한 스타일 가이드 초안을 만든다.
6. 샘플과 초안을 사람 검수로 제시한다.

## 승인 후 적용

사람이 명시적으로 승인한 뒤에만 스타일 가이드를 정본 위치에 저장하고 `pipeline/scripts/manifest.py`로 `style_guide`를 등록한다. 승인 전에는 잠금 완료로 표시하지 않는다.

## 제한

- 학습 입력이나 모델 식별자에 비밀값을 기록하지 않는다.
- 승인 없이 art gen으로 넘어가지 않는다.
- manifest를 직접 편집하지 않는다.
