# P5 A 방향 대표 기물 컨셉

- 단계: `art concept`
- 목적: 선택된 A 보드와 함께 Flickstone 제출용 무학습 생성의 참조로 사용할 대표 재질 7종
- 규격: 512×512 PNG 컨셉, 원형 토큰, 진영색 미포함
- 종류: 바둑돌, 병뚜껑, 원시인, AI, 탱탱볼, 체스 나이트, 불 원소
- 생성 모델: Scenario FLUX.2 Dev (`model_bfl-flux-2-dev`)
- 런타임 연결: 금지. 사용자 승인에 따라 범용 파이프라인의 `art lock`은 사용하지 않으며, 참조 기반 테스트 샘플을 먼저 검수한 뒤 별도 P5 구현으로 64×64 런타임 에셋을 만든다.

사람 검수에서는 단일 원형 실루엣, 재질 구분, 64px 축소 가독성, 원 밖 돌출 여부, 텍스트·진영색 혼입 여부를 확인한다.

## 2026-08-25 생성·검사 결과

- 대표 7종과 바둑돌 대체안 1장, 총 8장을 생성했다.
- 모든 파일이 512×512 PNG RGB probe를 통과했다. 컨셉 검수용 배경이므로 알파 채널은 없다.
- 공통적으로 원형 실루엣, 좌상단 광원, 어두운 외곽 림, 진영색 미포함 조건을 만족한다.
- 최초 `baduk_stone_00.png`는 음양 문양으로 오인될 수 있어 잠금 입력에서 제외한다.
- 바둑돌 잠금 입력 권장안은 실제 검은 유광 돌 형태의 `baduk_stone_refined_00.png`다.

| 종류 | 잠금 입력 권장 파일 | 시각 판정 |
|---|---|---|
| 바둑돌 | `baduk_stone_refined_00.png` | 단순 유광 도자기, 실물 바둑돌 판독 양호 |
| 병뚜껑 | `bottle_cap_00.png` | 톱니 림과 긁힌 금속 재질 판독 양호 |
| 원시인 | `caveman_00.png` | 석재 얼굴 부조와 무거운 인상 판독 양호 |
| AI | `ai_core_00.png` | 회로와 단안 문양, 작은 크기 대비 양호 |
| 탱탱볼 | `bouncy_ball_00.png` | 고무·반투명 소용돌이 재질 판독 양호 |
| 체스 나이트 | `chess_knight_00.png` | 아이보리 나이트 부조 판독 양호 |
| 불 원소 | `fire_elemental_00.png` | 원 안에 봉인된 불꽃, 원 밖 돌출 없음 |

선택 보드 `../p5_map_board_a/p5_map_board_a_refined_02.png`와 위 7장을 합친 8장이 승인된 P5 참조 묶음이다. 커스텀 학습·스타일 가이드 등록은 진행하지 않으며, 첫 무학습 테스트는 `../p5_no_training_samples/`에서 검수한다.
