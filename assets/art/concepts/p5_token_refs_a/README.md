# P5 A 방향 대표 기물 컨셉

- 단계: `art concept`
- 목적: 선택된 A 보드와 함께 `art lock` 입력으로 검수할 대표 재질 7종
- 규격: 512×512 PNG 컨셉, 원형 토큰, 진영색 미포함
- 종류: 바둑돌, 병뚜껑, 원시인, AI, 탱탱볼, 체스 나이트, 불 원소
- 생성 모델: Scenario FLUX.2 Dev (`model_bfl-flux-2-dev`)
- 런타임 연결: 금지. 사람 선택과 별도 `art lock` 승인 후 64×64 런타임 에셋을 생성한다.

사람 검수에서는 단일 원형 실루엣, 재질 구분, 64px 축소 가독성, 원 밖 돌출 여부, 텍스트·진영색 혼입 여부를 확인한다.

## 2026-08-25 생성·검사 결과

- 대표 7종과 바둑돌 대체안 1장, 총 8장을 생성했다.
- 모든 파일이 512×512 PNG RGB probe를 통과했다. 컨셉 검수용 배경이므로 알파 채널은 없다.
- 공통적으로 원형 실루엣, 좌상단 광원, 어두운 외곽 림, 진영색 미포함 조건을 만족한다.
- 최초 `baduk_stone_00.png`는 음양 문양으로 오인될 수 있어 잠금 입력에서 제외한다.
- 바둑돌 잠금 입력 권장안은 실제 검은 유광 돌 형태의 `baduk_stone_refined_00.png`다.
