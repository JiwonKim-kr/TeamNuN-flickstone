# P5 A 방향 맵 보드 컨셉 후보

- 단계: `art concept`
- 용도: 런타임 적용 전 사람 선택과 Flickstone 제출용 무학습 생성의 보드 기준 참조
- 규격: 640×1,024 PNG, 보드 전용
- 제외: 기물, 배치 슬롯, HUD, 문자, 데미지/KILL 존, 내부 장애물
- 생성 모델: Scenario FLUX.2 Dev (`model_bfl-flux-2-dev`)
- 런타임 manifest/scene 연결: 금지. 사용자 승인에 따라 범용 `art lock`·`art gen`은 사용하지 않으며, 참조 기반 테스트 샘플 검수 뒤 별도 P5 구현으로 진행

사람 검수에서는 정투영 유지, 중앙 플레이 영역의 정숙성, 기물·데미지 존 overlay 대비, 외곽 프레임의 충돌 경계 오인 가능성을 우선 확인한다.

## 2026-08-25 생성·검사 결과

- 원본 프롬프트 2개 배치 6장과 외부 오브젝트 금지를 강화한 정제 프롬프트 4장을 생성했다.
- 전 파일이 640×1,024 PNG RGB이며 컨셉 배경이므로 알파 채널은 없다.
- `batch1_02`와 `batch2_00`은 SHA-256까지 같은 중복이다. `batch1_00`과 `batch2_01`은 육안상 근접 반복이다.
