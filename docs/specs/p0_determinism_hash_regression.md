## 스냅샷 필드

최소한 시뮬레이션 스텝, RNG 스트림 상태, 본체의 안정 ID·생존 상태·위치·속도·반지름·무게·마찰, 존과 경계의 결정론 관련 필드, 미정산 이벤트를 포함한다. 본체·존·이벤트는 각각 승인된 안정 키로 정렬한다.

## 수용 기준

1. 스냅샷은 Dictionary 순회나 로캘, 줄바꿈, JSON 키 순서에 의존하지 않는 명시적 필드 순서로 인코딩한다.
2. 정수는 고정 엔디언·고정 폭으로 기록하고 문자열은 길이와 UTF-8 바이트를 명시한다.
3. 동일 시드·입력·초기 상태를 1,000회 실행한 최종 해시가 모두 같다.
4. 본체와 존의 삽입 순서를 무작위로 바꿔도 최종 해시는 같다.
5. 입력 각도·파워·입력 스텝 중 하나만 바꾸면 해당 골든 시나리오의 결과 해시가 달라진다.
6. 골든 시나리오는 최소한 원-원 충돌, 다단 충돌, 벽 반사, 테두리 소멸, 내부 소멸, 서브스텝을 각각 포함한다.
7. 회귀 실패 로그는 시드, 입력 시퀀스, 최초 불일치 스텝, 기대·실제 해시를 출력한다.
8. `run_p0_determinism.py`는 `verify --full`에서 자동 발견된다.
9. CI는 최소 Linux와 Windows에서 같은 골든 해시를 비교한다.
10. 골든 해시 갱신은 의도된 시뮬레이션 계약 변경과 승인 근거가 있을 때만 수행하며, 변경 전후 값을 리뷰에 표시한다.
