## 목표

현재 전투가 체력 대비 낮은 공격력 때문에 오래 지속된다는 플레이 피드백을 반영한다. 정식 기물의 공격력만 약 25% 높여 기준 조건에서 동급 체력 기물을 처치하는 직접 적중 횟수를 약 5회에서 4회로 줄인다.

## 승인 기준

- 정식 기물 5종 `baduk_stone`, `bottle_cap`, `bouncy_ball`, `caveman`, `ai_core`의 모든 레벨 공격력을 기존 값의 1.25배에 가장 가까운 정수로 조정한다. 정확히 `.5`면 높은 정수로 반올림한다.
- 결과값은 다음과 같다.

| 기물 | L1 | L2 | L3 |
|---|---:|---:|---:|
| 바둑돌 | 25 | 31 | 38 |
| 병뚜껑 | 30 | 38 | 45 |
| 탱탱볼 | 25 | 31 | 38 |
| 원시인 | 23 | 29 | 34 |
| AI | 23 | 29 | 34 |

- `graybox_striker`는 P2 검증 기준값이므로 공격력 20을 유지한다.
- HP, 속도, 질량, 반지름, 마찰, 탄성, 치명타, 능력 계수는 바꾸지 않는다.
- 적은 기존처럼 base piece를 상속하므로 정식 기물 기반 적의 공격력도 함께 오른다. 별도 적 override는 추가하지 않는다.
- 원시인의 clean-launch 2배는 그대로 유지되어 L1 기준 최종 배율 적용 전 공격력 23을 사용한다.
- 데이터 schema version은 바꾸지 않고 canonical content fingerprint와 이를 포함하는 snapshot/golden만 이관한다.

## 비범위

- 시작 로스터·보상·편성·맵·적 구성 변경
- 피해 공식, 속도 배율, 체력 하향
- `graybox_striker` 제거 또는 정식화
- 최종 P6 밸런스 확정

## 수용 기준

1. 정식 5종의 L1~L3 공격력이 위 표와 정확히 일치한다.
2. `graybox_striker`와 모든 비공격 스탯은 변경 전과 같다.
3. runtime canonical fingerprint가 독립 Python과 Godot에서 일치한다.
4. RunSnapshot fingerprint KAT와 영향 P1/P2/P4 회귀가 통과한다.
5. 독립 전투를 실행해 사람이 전투 템포를 다시 검수할 수 있다.
