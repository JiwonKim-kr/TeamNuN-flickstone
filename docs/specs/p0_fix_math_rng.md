## 목적

플랫폼과 프레임률에 무관하게 같은 입력에서 같은 결과를 만드는 정수 기반 수학 계층과 프로젝트 소유 PRNG를 제공한다. 이후의 모든 시뮬레이션 상태는 이 계층만 사용한다.

## 수용 기준

1. `src/core/sim/` 구현은 `Node`를 상속하지 않고 Godot API를 호출하지 않는다.
2. 런타임 시뮬레이션 상태에 `float`를 저장하지 않는다. 화면·입력 경계에서만 승인된 양자화 함수를 통해 변환한다.
3. 사칙연산·제곱근·벡터 정규화는 승인된 테스트 벡터와 오차 한계 안에서 일치한다.
4. 삼각함수는 고정 각도 입력에 대해 룩업 테이블과 정수 보간만 사용하며, 테이블 생성 결과가 재현 가능하다.
5. 동일 시드의 `SimRng`는 1,000개 이상의 공개된 골든 벡터와 정확히 일치한다.
6. 서브시드 파생은 부모 스트림의 소비 위치를 바꾸지 않으며, 전투·AI 사본용 스트림을 분리할 수 있다.
7. 나눗셈 0, 길이 0 정규화, 최소·최대 표현 범위의 동작을 명시적으로 처리한다.
8. 승인된 최대 좌표·속도·무게 범위에서 중간 곱셈이 `int64`를 넘지 않는다는 계산 근거와 경계 테스트가 있다.
9. `run_p0_math_rng.py`는 `verify --full`에서 자동 발견되고, 실패 시 어떤 골든 벡터가 어긋났는지 출력한다.

## 확정된 결정

- 저장 형식: **`int64` + 소수부 16비트** (`FIX_SCALE = 65,536`, Q47.16)
- 표준 전장의 긴 변: 약 **1,000 논리 단위**
- 위치 지원 안전 범위: **±8,192 논리 단위**
- 속도 벡터 크기 안전 상한: **4,096 논리 단위/초**
- P0·P1 초기 밸런스 발사 상한: **2,048 논리 단위/초**
- 물리 무게 안전 범위: **1~256**
- 임펄스 절댓값 안전 상한: **2,097,152**
- 범위 밖 설정·콘텐츠 데이터는 clamp하지 않고 로드·테스트에서 실패시킨다.
- 고정 각도: 한 바퀴 **65,536단위**, `0=+X`, 화면 기준 시계 방향 증가, `& 0xFFFF` 순환
- 삼각함수 LUT: 사분면 **4,096구간·4,097개 Q47.16 값**, 선형 보간, 나머지 사분면 대칭 계산
- PRNG: **`xoshiro128**`**, `uint32` 4워드를 `int64`에 저장하고 매 연산 뒤 `& 0xFFFFFFFF`
- 런 시드: 64비트, 저장·표시는 16자리 16진수
- 서브스트림: `루트 시드 + 용도 ID + 안정 소유 ID + 순번`, 부모 스트림 비소비
- 시드 혼합: `fmix32` + 오버플로 없는 `mul_u32`
- 범위 난수: rejection sampling, 확률 판정: 정수 `numerator / denominator`
- 전투 효과와 AI 평가 RNG를 분리하고 스냅샷에 상태 4워드·소비 횟수를 기록한다.
- 전부 0인 PRNG 상태는 금지한다.
- 기본 반올림: **최근접, 정확히 절반이면 0에서 먼 방향** (`+1.5→+2`, `-1.5→-2`)
- 곱셈·나눗셈·LUT 보간·입력 양자화는 같은 반올림 규칙을 사용하고, 제곱근의 절반은 위쪽으로 보낸다.
- `floor`·`ceil`·`trunc`는 이름 있는 헬퍼로만 명시적으로 사용한다.
- 암묵적 절삭·포화 연산·조용한 clamp를 금지하고 0 나눗셈·범위 밖 중간값은 실패 처리한다.
- 렌더 픽셀과 논리 단위는 분리한다.
- Q47.16의 이론상 전체 범위가 아니라 승인된 안전 영역만 물리 연산에 사용한다.

P0-1의 사전 기술 결정과 명세 전체가 승인되었다. 승인된 대상 파일과 수용 기준 범위에서 구현할 수 있다.
