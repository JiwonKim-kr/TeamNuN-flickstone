# P5-CS 전투 효과음 최소 구성

- status: approved
- approved: 2026-08-26
- scope: 제출용 전투 수직 슬라이스의 타격 피드백

## 승인 구성

1. `se:combat/impact`: 피해를 발생시킨 기물 충돌의 공용 타격음.
2. `se:pieces/bouncy_ball_rebound`: 탱탱볼이 벽 또는 기물에 반발할 때 공용 타격음 위에 중첩하는 반발음.
3. `se:pieces/caveman_clean_hit`: 원시인의 정상 발사 후 벽·아군 접촉 전 2배 피해가 실제 적용된 타격에 중첩하는 묵직한 타격음.

AI 코어에는 별도 효과음을 붙이지 않는다. AI의 차별점은 조준 경로 표시와 선택 규칙으로 유지한다.

## 생성·규격

- 백엔드: 로컬 `jsfxr`(외부 API 비용 없음).
- 재현성: 각 엔트리의 seed와 resolved params를 보존한다.
- 출력: OGG Vorbis, mono, 44,100 Hz, -16 LUFS, true peak -1.5 dBTP 이하.
- 짧은 원음은 BS.1770 분석을 위해 끝에 무음을 보충하되 실제 파형은 늘이지 않는다.
- 생성본은 사람의 청음 승인 전에 런타임에 연결하지 않는다.
- 사운드 디렉션: 공용 충돌음과 원시인은 고역을 억제한 둥탁한 타격으로, 탱탱볼은 원형 고무의 탄성과 피치 이동이 느껴지는 “보잉”으로 한다.

## 런타임 연결 규칙

- `src/core/` 시뮬레이션은 오디오를 모른다. 결정적 전투 결과를 표현 계층의 신호로 변환해 재생한다.
- 공용 타격음은 실제 피해가 1 이상 확정된 충돌 이벤트당 1회 재생한다.
- 탱탱볼 반발음은 해당 충돌에 탱탱볼이 포함되고 탄성 배율이 1보다 클 때만 재생한다. 동일 기물은 80ms 재생 제한을 둔다.
- 원시인 클린 히트음은 `clean_launch_damage_multiplier > 1` 이 실제 피해에 반영된 경우만 충돌 시퀀스당 1회 재생한다.
- 추가 효과음은 공용 타격음을 대체하지 않고 중첩해 기물의 차이를 즉시 알려준다.
