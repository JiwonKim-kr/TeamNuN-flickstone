## 수용 기준

1. 원-원 충돌은 정본 4.4의 접근 상대속도, 반발계수, 역질량 임펄스 공식을 고정소수점으로 계산한다.
2. 이미 멀어지는 원 쌍에는 임펄스를 다시 적용하지 않는다.
3. 겹침은 무게 역비로 즉시 분리하며, 같은 초기 상태에서는 항상 같은 보정 결과를 낸다.
4. 충돌 후보와 해결 순서는 `(낮은 ID, 높은 ID)` 쌍의 사전식 오름차순으로 고정한다.
5. 한 스텝 이동량이 최소 반지름의 절반을 넘으면 필요한 만큼 서브스텝을 사용한다.
6. `WALL` 경계는 순수 반사만 수행하며 P0 파괴 사건을 만들지 않는다.
7. `KILL` 경계 바깥과 내부 `KILL` 존은 같은 소멸 판정 함수와 같은 `BODY_DESTROYED` 사건을 사용한다.
8. 소멸 판정에는 속도·체력·무적 조건을 적용하지 않는다.
9. 소멸된 본체는 현재 반복을 무효화하지 않도록 정렬된 정산 단계에서 한 번만 제거된다.
10. 최대 속도 스트레스 시나리오를 대량 실행했을 때 허용치를 넘는 관통·중복 파괴·비결정 결과가 0건이다.
11. `run_p0_collision_boundaries.py`가 `verify --full`에서 자동 발견되고 실패한 시드·스텝·본체 쌍을 출력한다.
12. `destructible=false` 본체도 경계·존 소멸에서 정확히 한 번 `BODY_DESTROYED`가 발생한다.
13. 관리 제거는 `BODY_REMOVED`만 발생시키며 `BODY_DESTROYED`와 혼동되지 않는다.

## 확정된 결정

- 소멸 판정은 기물 중심점 기준. 경계선 위는 안전, 엄격한 내부 진입·외곽 이탈 시 소멸
- 매 서브스텝의 이전→새 중심 선분을 검사하고 여러 영역이면 최초 교차 사용
- 초기 배치가 소멸 영역 내부면 데이터 실패, 이후 순간이동 도착은 즉시 소멸
- 외곽 경계는 화면 기준 시계 방향의 단순 볼록 폴리곤, 3~64정점, 위치 범위 ±8,192
- 내부 존은 자기 교차가 없는 단순 오목 폴리곤까지 허용
- 자기 교차·중복 정점·0길이 변·연속 일직선·면적 0·잘못된 외곽 방향·오목 외곽은 로드 실패
- 오목 외곽은 P0 이후 내부 장애물 또는 검증된 볼록 분해로 확장
- `edge_index`는 시작 정점 인덱스, 안쪽 법선은 시계 방향 변의 왼쪽 수직선
- 다중 접촉은 관입 깊이 내림차순→`edge_index` 오름차순으로 모두 처리
- 변 내부 접촉은 변 법선, 공유 꼭짓점은 꼭짓점→중심 법선. 중심과 꼭짓점이 같으면 인접 안쪽 법선 합을 정규화
- 공유 꼭짓점 이벤트는 낮은 인접 edge가 한 번만 소유
- 위치 보정은 항상, 속도 반사는 벽을 향해 이동할 때만 수행. 재검사 64회 내 미해소 시 실패
- 기본 반발계수 `17/20`(Q47.16 raw 55,706), 원-원·벽 공통, 허용 범위 `0 이상 1 미만`
- 반지름 8~128(기본 32), 무게 1~256(기본 64)
- 시험 속도 512·1,024·2,048, 안전 한계 스트레스 4,096
- 탄성 강화는 `1 - (1-e)/N` 공식만 사용
- 기본 틱 시작 시 마찰·외부 가속도를 한 번 적용한 뒤 월드 공통 `N=max(1, ceil((최대속도/120)/(최소반지름/2)))` 계산
- 위치 이동 DT는 정확한 `1/(120×N)`, 마찰·가속도는 서브스텝마다 재적용하지 않음
- 활성 기물이 없으면 N=1, 최대 N=16, 이벤트 substep은 0~15
- N>16이면 이동 전 `SIM_LIMIT_EXCEEDED` 실패. 속도·N clamp 금지
- `SimBody.destructible: bool`을 P0부터 저장하고 스냅샷·해시에 포함, 기본값 true, 비-boolean 데이터 실패
- 일반 파괴는 플래그를 확인하지만 경계·존 소멸은 항상 무시
- 소멸 이벤트는 공통 `BODY_DESTROYED`, cause만 `KILL_BOUNDARY`·`KILL_ZONE`으로 구분하며 트리거 타입은 분리하지 않음
- `remove_body()`는 관리 제거로 `BODY_REMOVED`만 발생시키고 destructible을 확인하지 않음

P0-3의 사전 기술 결정과 명세 전체가 2026-08-18 사용자 승인으로 확정되었다.
